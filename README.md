# Don galleto

Sistema de gestión de galletas

## Inicio de proyecto python

- Clona el repositorio con: `git clone https://github.com/migueldr12/Don-Galleto.git`
- Crea tu entorno virtual, primero en la consola escribe el comando: `py -m venv venv`
- Activa en tu entorno virtual: `env\Scripts\activate`
- Ya esta el archivo con todas las dependencias necesarias, solo ejecuta el comando: `pip install -r requirements.txt`
- Hostea tu aplicación con el comando: `flask --app main --debug run`

### Instalación para utilizar tailwind.css

- Previamente debes tener instalado una versión de LTS de Node.js. Luego, en terminal ejecuta el comando: `npm install`
- Luego, solo hay que ejecutar el comando de: `npm run init`
- Los estilos que se van a modificar van a ser desde static/src/input.css, pero se pueden añadir directamente a las clases en html:
